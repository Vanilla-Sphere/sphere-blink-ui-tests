## Suite architecture (this round's direction from Duy)

- `00-fast.spec.ts`: instant, no-data-fetch checks — run first, fully parallel.
- `journey.spec.ts`: one continuous serial flow through every data-loading
  feature, sharing one browser state per project (worker-scoped `sharedPage`).
- `api-list.spec.ts` / `completeness.spec.ts` / `regression.spec.ts`:
  self-contained serial files.
- `workers: 4`; at most two view loads touch the shared service at once.
- Full-suite wall time: **3.6 minutes** (the pre-refactor runs took 13–30).
