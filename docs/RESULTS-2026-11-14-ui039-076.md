## Build drift observed (production ahead of the baseline commit)

The live build (assets `?v=54`) is ahead of `0d8474f` (`?v=50`). Two behaviour
changes were found and handled:

1. **Touch height is pointer-driven**: `.btn … {min-height:40px}` moved from
   the 760 px media query to `@media (pointer:coarse)`. UI-074 now asserts the
   coarse-pointer rule plus the width markers that still hold (`#search` row
   breakpoint moved to 1000 px; rail collapse still at 760 px).
2. **Card-row fade on the map**: the commit fades the cards when the map is
   zoomed (`.mapscreen.zoomed`); the deployed build fades them while the map
   moves (`.mapscreen.moving`). UI-042's zoom-fade leg is annotated as
   build-dependent (partial); the full-screen and phone-scroll legs are
   asserted.

The CI workflow of this repository runs the suite against each deployment, so
future drift surfaces as a red run rather than a stale pass.
